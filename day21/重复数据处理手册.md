# 重复数据处理手册（C++ / 竞赛入门）

> 用法：拿到一道"有重复"的题，**先翻到「先问四个问题」**，回答完再决定用哪个模型。  
> 不要一进题就想"怎么写代码"——先想"这道题的重复是什么性质"。

---

## 一、先问四个问题

遇到任何带"重复"的题，按顺序回答：

1. **重复的是什么？** —— 一个**值**？一个**位置**？还是**一对数据**？
2. **我要对它做什么？** —— **去掉**它？**数**它几次？**留**特定的那个？还是**根本不许它发生**？
3. **顺序重要吗？** —— 输出要保持原来的先后顺序，还是只要结果？
4. **数据范围多大？** —— 决定能不能开"桶"（值直接当下标）。

四个答案一出来，用哪个模型基本就定了。

---

## 二、四类核心模型

### 模型 1 · 标记型（bool 桶）—— 只问"出现过没"

**什么时候用**：去重、判断"有没有"、收集不同的值。  
**关键性质**：**幂等** —— 同一个动作做一遍和做一百遍，结果一模一样。重复的输入自动失效，你不用写任何"删除"。

```cpp
bool seen[MAXN] = {0};
seen[x] = true;            // 第 1 次和第 100 次执行，效果相同
// 之后扫下标处理
```

**你做过的**：

- P5729 工艺品制作 —— "这个位置被切过没"（重复的是**位置**）
- P1059 明明的随机数 —— "这个数字出现过没"（重复的是**值**）

**变体：检测"有没有重复"（只要回答 yes/no）**

```cpp
bool seen[MAXN] = {0}, dup = false;
for (int i = 0; i < n; i++) {
    int x; cin >> x;
    if (seen[x]) dup = true;   // 写之前先查
    seen[x] = true;
}
```

**变体：保序去重（去重但保持原输入顺序）**

```cpp
bool seen[MAXN] = {0};
for (int i = 0; i < n; i++) {
    if (!seen[a[i]]) {
        cout << a[i] << " ";   // 只输出"第一次见到"的
        seen[a[i]] = true;
    }
}
```

---

### 模型 2 · 计数型（int 桶）—— 问"出现了几次"

**什么时候用**：频数统计、众数、出现 k 次的、出现奇数/偶数次的。  
**关键性质**：不是"要不要"，而是"几次"——所以格子不能是 bool，要能装数字。

```cpp
int cnt[MAXN] = {0};
cnt[x]++;                    // 每来一次就 +1
```

**你做过的**：

- P1554 梦中的统计 —— 数码 d 出现几次，答案就是 `cnt[0..9]`

**延伸问法**（同一段代码，只改最后的判断）：

- 出现次数最多的 → 扫一遍找 `cnt[i]` 最大
- 恰好出现 k 次 → `if (cnt[i] == k)`
- 只出现 1 次（没重复） → `if (cnt[i] == 1)`

---

### 模型 3 · 结构型 —— 让重复**根本没机会发生**

**什么时候用**：配对、组合、对称问题。重复的是"一对数据"或"对称的另一半"。  
**核心想法**：模型 1/2 是"先产生、再筛掉"，模型 3 是**从枚举顺序上堵死**，压根不产生重复。这是高一个档次的思维。

**你做过的**：

- P5728 旗鼓相当的对手 —— `for (j = i+1; ...)` 保证 (i,j) 和 (j,i) 只算一次

**常见手法**：

```cpp
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)   // 无重复配对（组合）
```

- 只枚举一半（回文、对称）
- 规定"小的在前"（`i <= j`，允许取等时是**排列 vs 组合**的分水岭）

**判断信号**：只要题里出现"两两""任意两个""配对""组合"，先想模型 3，不要先想桶。

---

### 模型 4 · 排序后处理 —— 让相同的元素**自动挨在一起**

**什么时候用**：值域太大开不了桶；或者题目本来就要排序。  
**核心性质**：排序之后，**相同的元素必然相邻**。于是一堆难题都变成"看相邻两个"的事。

| 需求      | 排序后怎么做    |
| ------- | --------- |
| 去重      | 跳过与前一个相同的 |
| 数每种出现几次 | 数连续相同段的长度 |
| 找重复的    | 看相邻是否相等   |
| 第 k 大/小 | 直接按下标取    |

**骨架（排序 + 保序去重）**：

```cpp
sort(a, a + n);
int m = 0;
for (int i = 0; i < n; i++)
    if (i == 0 || a[i] != a[i-1]) a[m++] = a[i];
// a[0..m-1] 就是去重后的结果
```

> 注意：P1059 明明的随机数其实**两种都能做**——你选的标记型更省，排序型更通用（值域大时只能用它）。

## 三、你的 4 道题，对号入座

| 题             | 重复的是                 | 要做什么       | 模型        |
| ------------- | -------------------- | ---------- | --------- |
| P5729 工艺品制作   | 空间**位置**被多次切         | 只问"被切过没"   | 标记型       |
| P1554 梦中的统计   | 数码**值**出现多次          | 数**几次**    | 计数型       |
| P5728 旗鼓相当的对手 | **一对**数据 (i,j)/(j,i) | 不许重复**发生** | 结构型       |

**你已经用过 3 类了**（标记 / 计数 / 结构）。缺的只是"看到题先认出该用哪类"这一步。

## 四、还会碰到的（补充类型）

1. **保序去重**：见模型 1 变体。题目说"按输入顺序输出去重后的"就用它。
2. **保留最后/最新的**：同一个键多次写入，只留最后一次 → 直接赋值天然覆盖。
   ```cpp
   int last[MAXN] = {-1};
   last[x] = i;   // 后写的自动盖掉先写的，不用特判
   ```
3. **检测有没有重复**：见模型 1 变体（边读边查）。
4. **连续段压缩**（run-length：`aaabbc` → `a3b2c1`）—— 遍历 + 当前值计数器，值一变就结算。
   ```cpp
   for (int i = 0; i < n; ) {
       int j = i;
       while (j < n && a[j] == a[i]) j++;
       // a[i] 连续出现了 (j - i) 次
       i = j;
   }
   ```
5. **值域太大开不了桶** → 排序后处理（模型 4），或 `set<int>`（自动去重 + 自动有序）。
6. **窗口内的重复**（如"最长不含重复字符的子串"）→ 双指针 + 标记，后面会学，先知道有这回事。

## 五、决策入口（背这个流程）

```
重复的是什么？
├─ 值 → 我要做什么？
│   ├─ 去掉它 → 顺序要保吗？
│   │   ├─ 要保序 → 模型 1 变体（标记 + 原序扫描）
│   │   └─ 不保序 → 值域小 → 模型 1（标记桶）
│   │              值域大 → 模型 4（排序去重）或 set
│   ├─ 数它几次 → 模型 2（计数桶）
│   └─ 留特定的那个 → 模型 1 的"第一次见到" / 模型 6 的"覆盖"
└─ 一对数据 / 位置 → 能不能从结构上避免？
    ├─ 能（配对、组合、对称）→ 模型 3（首选！）
    └─ 不能 → 回到模型 1 / 2
```

**判断信号速查**：

- "两两 / 任意两个 / 配对" → 先想模型 3
- "出现几次 / 最多 / 频率" → 模型 2
- "去重 / 不同 / 出现过没" → 模型 1
- 值域 > 10^7 → 别开桶，想模型 4

---

## 六、写完自检

每写完一道"重复"题，问自己三句：

1. 这题的**重复是什么**？（值 / 位置 / 一对）
2. 我用的是**哪一类**？换个类能不能做？
3. 我有没有把"**不许它发生**"（模型 3）和"**发生了再筛**"（模型 1/2）搞混？

这三句能答上来，这类题你就真的拿下了。
