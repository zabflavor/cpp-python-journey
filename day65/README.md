# gpa-tool · GPA 计算工具

## 一、这个项目是干什么的

输入一张成绩表（scores.txt：课程名 分数 学分），按学校规定的换算规则把每门分数转成绩点，再按学分加权算出总 GPA，把每门课的贡献分和最终 GPA 写进 result.txt。

这是 W10 项目 gpa-tool 的第一天版本，目前只完成了 C++ 命令行版。后续几天会继续加功能。

## 二、怎么编译运行

在 day65 目录下执行：

```
mkdir -p build
clang++ gpa.cpp -o build/gpa
./build/gpa
```

运行前确认 scores.txt 在同一目录下。跑完打开 result.txt 看结果。

## 三、GPA 换算规则（4.0 制）

| 分数区间 | 绩点 |
|---|---|
| 90 – 100 | 4.0 |
| 85 – 89  | 3.7 |
| 82 – 84  | 3.3 |
| 78 – 81  | 3.0 |
| 75 – 77  | 2.7 |
| 72 – 74  | 2.3 |
| 68 – 71  | 2.0 |
| 64 – 67  | 1.5 |
| 60 – 63  | 1.0 |
| < 60     | 0   |

加权公式：GPA = Σ(每门绩点 × 该门学分) / Σ学分

举例：Math 92 分（绩点 4.0）× 3 学分 = 12.0，PE 59 分（绩点 0）× 1 学分 = 0——不及格的课绩点为 0，但学分照样进分母。

## 四、当前文件

· result.txt —— 输出：每门课的贡献分 + 最终 GPA
